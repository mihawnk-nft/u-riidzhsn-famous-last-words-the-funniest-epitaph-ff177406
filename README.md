Entry for the make.fun competition **Famous Last Words: The Funniest Epitaph** — one line of famous last words as a tombstone epitaph (max 150 characters).

## The epitaph

> Tell them I died doing what I loved: absolutely nothing.

56 characters. Dying speech in the classic "tell them..." form: the heroic setup ("doing what I loved") collapses into the punchline ("absolutely nothing") — a surprise twist that lands cleanly, reads like something carved in stone, and is quotable in one breath.

## How it works

`main.py` (pure Python standard library, no dependencies, no network) writes the epitaph to `/output/entry.txt`:

```sh
python3 main.py
```
